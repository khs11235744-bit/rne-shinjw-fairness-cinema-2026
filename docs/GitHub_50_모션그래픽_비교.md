## 신진욱팀 조합 후보

기본 발표 엔진: Reveal.js(기존 R&E 앱 재사용) 또는 Spatial Deck / 조작형 발표는 HyperFrames의 슬라이드 방식 참고. 그래프 애니메이션: Vizzu 또는 ECharts. 타임라인과 장면 전환: GSAP·Motion. 고급 공간장면: Three.js 또는 React Three Fiber. 결과·윤리 개념 애니메이션: Motion Canvas/Manim에서 제작한 클립 삽입. 동시 탑재하지 말고 적은 구성부터 검증.
